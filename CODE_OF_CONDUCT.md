# Code of conduct

actp follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be respectful, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks are not welcome, in any form, in issues, pull requests or anywhere else this project lives.

## Reporting

If someone's behaviour worries you, contact the maintainers privately through the **Security** tab → **Report a vulnerability** (it reaches only the maintainers), and say it is a conduct report. We will read it, keep it confidential, and respond.

Maintainers may remove comments, commits or other contributions that break this code, and may ban people from the project, as described in the Contributor Covenant's enforcement guidelines.
